# Vishwas Website

A static personal website for Vishwas — Developer, Consultant, Educator.

## Features
- Modern, responsive design
- About, Services, Portfolio, and Contact sections
- No backend required (static form)

## Getting Started

1. Open the `src/index.html` file in your browser to view the website.
2. Customize content in `index.html`, `style.css`, and `script.js` as needed.

## File Structure

```
src/
  index.html   # Main website file
  style.css    # Stylesheet
  script.js    # JS for contact form
```
